# 11 · Design Backlog

> **Status:** Actionable design/UX backlog (docs-only; nothing here is implemented by this doc). Derived from the route/component audit of `app.saroh.in` + `@saroh/ui` on 2026‑07‑20.
> **Anchor:** _Saroh Canvas_ — one product, one primary action per screen, progressive disclosure, minimize clicks, teaching empty states, explaining success states.
> **Ranking:** by **Impact** first (High → Med → Low), then effort ascending. Effort = S (≤1 day), M (2–4 days), L (1–2 weeks).
