# Admin Control Plane Flow Preview

This is a non-production, standalone preview of the approved Saroh admin flow.
It uses representative data and performs no API requests or live mutations.

## Flow

1. Dashboard risk queue and role-aware briefing.
2. Organization search and reason-bound access.
3. Organization 360-degree workspace and explicit actions.
4. Operations diagnosis, dry runs, retries, and incidents.
5. Release cohorts, effective-value inspection, and rollback flow.
6. Team roles and staff lifecycle.
7. Immutable, redacted platform audit.

Open `index.html` through a localhost-only static server. The preview is
responsive and includes keyboard-accessible navigation and `Command/Ctrl + K`
search focus.

The screenshots in `screenshots/` are browser-validated captures at desktop
and mobile widths.
