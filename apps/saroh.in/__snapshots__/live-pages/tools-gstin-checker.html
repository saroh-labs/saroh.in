GSTIN checker: check a GST number's format

Paste a GSTIN to check its length, state code, PAN part and check digit. It's checked in your browser and never sent anywhere, so it can't look up the business's name. How it works out

Characters 1–2: state code
Characters 3–12: the business's PAN
Character 13: which registration this is for that PAN in the state
Character 14: Z by default
Character 15: check digit, worked out from the first 14

Questions

Does a correct format mean the GSTIN is real?

No. A right format means it was typed the way a GSTIN is built, and its last character fits the other 14. It doesn't mean the number was ever issued, or that the business is still registered.

To see the business's name and whether its registration is active, search the number on the GST portal.

Why can't it show the business's name?

The name is held by the GST network, and this tool doesn't send what you type anywhere. That keeps your customers' numbers private, but it means the tool can only check the number itself.

What does the 13th character mean?

It counts the registrations one PAN holds in the same state. A business with one registration in Karnataka has 1 there; a second registration in the same state, for another branch or line of business, gets 2.

Can I check a list of GSTINs at once?

Yes. Pick Check a list and paste them one per line. Each gets its own result, and you can get the results as a spreadsheet by email.

State codes follow the GST list, for example 07 Delhi, 24 Gujarat, 27 Maharashtra, 29 Karnataka, 33 Tamil Nadu and 36 Telangana, so a list from many states is checked the same way.
