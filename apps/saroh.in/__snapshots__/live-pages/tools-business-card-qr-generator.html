Questions

What is a vCard?

A vCard is the standard format phones use for a contact. The code holds your details in that format, so a phone opens it as a new contact, ready to save.

Does it work without an app?

Yes. The camera on iPhones and on most Android phones reads the code and offers to add the contact. Nothing needs installing.

My number changed. Will the old cards still work?

The old cards still open, but they save the old number. The details are inside the code, so make a new code and print new cards when your number changes.

How small can I print the code?

Print it at least 2 cm wide for a name and phone only. With an email, website and address the code gets denser, so print it larger, or leave the address off.
