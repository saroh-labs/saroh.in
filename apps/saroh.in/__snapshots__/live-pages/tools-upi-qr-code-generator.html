Questions

Does this work with every UPI app?

Yes. The code is a standard UPI payment link, the same kind printed at shop counters, so Google Pay, PhonePe, Paytm, BHIM and bank apps all read it.

Scan it once with your own phone and check the name your app shows before you print it.

Is my UPI ID saved anywhere?

No. The code is drawn in your browser, and what you type is not sent to Saroh or anyone else.

If you leave your email to get the file, only the email is sent.

Should the QR code have an amount in it?

For a counter or a shop door, leave it empty, so each customer types what they owe.

Put an amount in only for one fixed price, like a class fee or a single order. The customer can't change it, so a wrong amount means a new code.

Which name does the customer see?

The UPI app shows the name on the bank account linked to your UPI ID. The name you type here is printed on the card, so make it match, and customers can check they are paying the right shop.
