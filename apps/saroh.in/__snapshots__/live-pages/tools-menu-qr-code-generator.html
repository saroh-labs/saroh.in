Menu QR code generator

How it works

  1. Paste the link where your menu already lives: your website, a Drive file, or a delivery app page.
  2. Add a table number and a few favourites if you want them printed on the card.
  3. Scan the code once with your own phone before you print.
  4. Change the menu at that link any time; the printed code keeps working as long as the link does.

Questions

Can I put my whole menu inside the QR code?

No. A QR code holds a link or a few words. A whole menu would make the code too dense for most phones to read, so the code points to where your menu lives.

I have my menu as a PDF. What do I do?

Give it a link first. Put the PDF or photo on Google Drive, set sharing to Anyone with the link, and paste that link here.

Scan the code once on a phone that isn't signed in to your Google account, to check customers can open it.

Do I need a new code when my prices change?

No, as long as you change the menu at the same link. The code holds the link, not the menu.

Only the favourites printed on the card need printing again when their prices change.

What size should I print it?

Print the code at least 3 cm wide, so phones can read it from a seat. A card the size of a postcard is easy to read across a table.
