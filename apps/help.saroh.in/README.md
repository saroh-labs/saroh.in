# help.saroh.in

Product help for Saroh end users: how to use the dashboard, pricing, account, and other product features.

- **Audience:** People using Saroh to create blogs, portfolios, or storefronts (not developers contributing to the repo).
- **Stack:** Nextra, same as docs.saroh.in; uses @saroh/ui and shared tooling.

## Run locally

```bash
pnpm dev
```

Runs on port 3007.
