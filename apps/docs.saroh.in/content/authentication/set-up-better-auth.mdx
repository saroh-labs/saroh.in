## Set up Better Auth for authentication in Saroh.io

Authentication is powered by [Better Auth](https://www.better-auth.com/). The
Better Auth server is hosted by the API (`api.saroh.in`), and `accounts.saroh.in`
provides the sign-in UI. Apps consume the shared `@saroh/auth` package rather than
configuring auth themselves.
