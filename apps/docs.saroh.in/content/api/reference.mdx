## Reference: secret key

Every call on `/v1` takes a secret key in `Authorization: Bearer sk_live_…`.
A call needs the right named under it, in both the key and its maker's
role. Writes take an [`Idempotency-Key`](/api/idempotency). Refusals are
described in [Errors](/api/errors).
