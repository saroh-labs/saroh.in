# Content blocks: one component per board block

Plan 2026-10-31-002 U4, DEC-195. Every block the SEO canvas repeats on the
GST, guides and downloads boards is drawn by exactly one component here. A
page passes props; a difference between boards is a prop or variant, never a
second drawing. Colours are the `--sp-*` tokens in `styles.css` (the site's
own layer, never `--site-*`). Desk is the 1440 board, phone the 390 board
(below 900px, as the rest of `.sp`).

Boards: SB = `SharedBlocks`, GST = `gst/<Page>` (+`Phone`), GU = `guides/Sample`,
GH = `guides/Hub`, DL = `downloads/Sample`, DH = `downloads/Hub`, SH = `gst/Hub`,
TA = `variants/TablesAPhone`.

## Board differences settled here (one component, one look)

- The GST boards' trail is 13.5px and starts at "GST guides"; SB, guides and
  downloads are 14.5px from Home. The trail is 14.5px; a page chooses `home`.
- GST Questions rows are smaller than SB's: the `compact` prop, not a copy.
- The rail on GST boards lists 4 more guides; R5 says 3, so `Related` shows 3.
- The four boards draw the stacked band at different sizes; `ClosingBand look="stack"`
  takes the GST numbers in a rail layout and the guide numbers in a solo column
  (from where it sits, not a second component). Every band's button is the shared
  52px `StartButton` (GST boards draw 48px).
- GST table cards title a row "Customer: In your state"; DoINeedGst,
  InvoiceOrBillOfSupply and the guide card use the cell alone. Cards use the cell alone.
- Byline line: GST 13px, downloads 13.5px; it is 13.5px.
- SB's band has a second "See a live demo" button; no content board does, so
  it isn't drawn.
- GST hub phone H1 is 40px, guides and downloads hubs 26px: hubs are 26px.
- Guide prose text is `#2E2C28` on the guide board: `--sp-prose`. GST sections use `--sp-body`.

`DownloadGate` belongs to U9: it goes in `ContentLayout layout="hero"`'s `aside`.
