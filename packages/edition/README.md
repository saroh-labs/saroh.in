# @saroh/edition

Each edition's profile (`EDITION_PROFILES`, `editionProfile()`): the facts code
asks instead of "is this India?" (DEC-204 item 7), and which hosts each edition
is served on. Pure data and types, safe for browsers and the API.

India is saroh.in and Global is saroh.tech. `hreflang.json` lists pages that do the same job on both
sites, which feeds the sitemaps. A pair must point both ways or Google ignores
it, so saroh.in's sitemap takes these once saroh.tech is live.
